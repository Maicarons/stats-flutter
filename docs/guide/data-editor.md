# 数据编辑器

在**工程工作区 → 数据** 中使用，含数据视图与变量视图。

## 双击编辑

- **双击**单元格进入编辑
- **长按**（触屏）同样可编辑
- **Enter** 确认并下移
- **Tab** 确认并右移（Shift+Tab 左移）
- **Esc** 取消（恢复原值）

表格自适应屏幕宽度：窄屏列宽均分填满，宽屏按内容伸展。行号固定，表头吸顶。

## 值标签

1. 展开变量 → **编辑值标签**
2. 输入「值 + 标签」→ 添加
3. 列表中可 **编辑 / 删除 / 清空全部**
4. Chip 上也可直接删除

**表格默认不显示值标签**，工具栏标签图标可切换显示。

## 缺失值

变量卡片可设置：

- 离散缺失值（如 `-99, -98`）
- 范围缺失（上下限）
- 空白单元格始终视为缺失

## 变量属性

类型（数值/字符串/日期）、测量（标度/有序/名义）、标签、小数位。支持**删除变量**。

## 导入导出

| 操作 | 说明 |
|------|------|
| 加载示例数据 | 30 个案 × 6 变量演示集 |
| 导入 CSV | 自动识别表头与数值类型 |
| 导出 CSV | 保存到文档目录，可分享/复制 |

## 右上菜单

- 数据变换 / 语法编辑器
- 加权个案（WEIGHT CASES）
- 拆分文件（SPLIT FILE）
- 查找个案
