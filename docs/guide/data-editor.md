# 数据编辑器

数据编辑器提供类 Excel 的浏览与编辑体验，对应 PSPP 的 Data Editor / Variable View。

## 双击编辑

- **双击**单元格进入编辑态
- **长按**（移动端）同样可进入编辑
- **Enter** 确认并下移一行
- **Tab** 确认并右移一列（Shift+Tab 左移）
- **Esc** 取消编辑

编辑时数值列只接受数字输入（含负号与小数点）。

## 视图切换

| 视图 | 作用 |
|------|------|
| 数据视图 | 个案 × 变量的矩阵，行号列固定，表头吸顶 |
| 变量视图 | 变量属性：类型、测量级别、标签、小数位、值标签 |

顶部搜索框可过滤个案或变量名。

## 值标签

在变量视图中为数值变量配置「值 → 标签」映射后，数据视图可一键切换「显示值标签」，用标签替换原始数值展示。

## 导入 / 导出

菜单中支持：

1. **加载示例数据** — 内置成绩与教学法演示集（30 个案 × 6 变量）
2. **导入 CSV…** — 自动识别表头与数值类型
3. **导出 CSV** — 保存到应用文档目录，可分享或复制到剪贴板

## 变量属性

| 属性 | 说明 |
|------|------|
| 类型 | 数值 / 字符串 / 日期 |
| 测量 | 标度 / 有序 / 名义 |
| 小数位 | 控制数值显示精度 |
| 标签 | 变量的可读描述 |

属性变更即时生效并参与后续分析。
