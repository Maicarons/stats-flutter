# 学习与测试

## 学习模块

8 课短课，按类别组织：

| 类别 | 课程 |
|------|------|
| 入门 | 描述统计基础 |
| 比较均值 | t 检验三兄弟、单因素方差分析 |
| 关系 | 相关分析 |
| 预测 | 线性回归 |
| 分类 | 卡方检验 |
| 稳健 | 非参数检验 |
| 测量 | 信度与量表 |

每课包含：

1. 分节概念讲解
2. **核心公式**（等宽字体展示）
3. 各方法在分析模块中的入口

## 测试模块

- 题库 **20 题**，覆盖描述、t 检验、ANOVA、相关、回归、卡方、非参数、信度
- 可选 5 / 10 / 15 / 20 题
- 随机抽题，作答即时选择
- 交卷后显示得分、评语，以及 **答题回顾**（正确项、你的选择、解析）

### 评分建议

| 得分 | 建议 |
|------|------|
| ≥ 80% | 可挑战更高题量，或在分析页实战 |
| 60–80% | 复习错题解析 |
| < 60% | 先完成「学习」模块相关课程 |

测验进度保存在内存中，可随时「再来一套」或「返回设置」。
