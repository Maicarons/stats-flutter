# 输出与导出

分析每运行一次，报告进入运行页的**输出树**。同一个分析可以反复运行，所有结果都留在会话里，导出格式有三种。

## 输出树

- **每次运行追加一张卡片**，最新的在最前面；上一次的结果不会被覆盖；
- 卡片默认**只展开最新一张**，其余折叠；点标题或左侧箭头手动展开 / 折叠，手动结果优先，再跑一次不会把旧卡片顶开；
- 输出树只在**当前会话**里存在（不写入工程、不跨启动保留）——报告随时可以重跑，避免读到过期结果；
- 表头显示**条数**，右侧「清空输出」二次确认后清空当前分析的全部卡片；
- 每张卡片：复制全文、分享（纯文本）、导出（PDF / HTML / Markdown）、删除。

## 导出

| 格式 | 说明 |
|------|------|
| **PDF** | 保留标题层级、斑马纹表格、页眉页脚与「第 x / y 页」；数值列右对齐，p 值列按显著性加星着色；中文用内置子集字体（`StatsSansSC`，OFL-1.1），不依赖系统字体 |
| **HTML** | 单文件、样式内联，浏览器直接打开或随邮件发出都行 |
| **Markdown** | 纯文本表格，方便贴进 wiki 或提交到版本库 |

三种格式都写到应用文档目录后调起系统分享。AppBar 上的「导出全部」把当前分析的**所有卡片合成为一份**：每份报告前加一条「标题 · 生成时间」的分隔小节，顺序与输出树一致（最新在前）。

## 表样式

屏幕、HTML、PDF 三种输出共用同一套判定，因此同一张表在哪里看都一样：

- **数值列右对齐**：识别 `12.5`、`.023`、`<.001`、`≤0.05`、`1.2e-05`、`1,204`、`12.5%`，也会忽略相关系数自带的尾随星号（`0.62 **`）；
- **p 值列**：`p < 0.05` 按档加星（`*` / `**` / `***`）并按显著性着色；
- **变量与值标签**：表中优先显示变量的**标签**（没有标签时回落变量名）；频数与交叉表显示**值标签**（如 `1 → 男`）；报告注释给出「标签 = 变量名」的对应关系，避免和变量名对不上。
