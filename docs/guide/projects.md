# 工程管理

主页是**工程列表**入口。每个工程对应一份独立的统计表。

## 工程列表

- **新建示例工程**：内置成绩与教学法演示数据
- **新建空白工程**：从零开始
- **打开**：进入工程工作区
- **重命名 / 复制 / 删除**
- 顶部搜索框过滤工程

卡片显示：名称、个案数、变量数、最近更新时间。

## 持久化

工程以 JSON 保存在：

```
<应用文档目录>/stats_flutter_projects/<id>.json
```

包含元数据（名称、描述、时间戳）与完整数据集（变量字典 + 个案）。

## 工程工作区

打开工程后，底部导航变为三个页签：

| 页签 | 功能 |
|------|------|
| **数据** | 表格编辑、变量视图、CSV、值标签、缺失值 |
| **分析** | 全部统计过程 |
| **变换** | COMPUTE / RECODE / SORT 等 |

顶部显示工程名与数据规模，可**保存工程**或**关闭工程**（自动保存并返回列表）。

## 与全局页签的关系

| 页签 | 位置 | 是否依赖工程 |
|------|------|--------------|
| 工程 | 全局 | — |
| 学习 | 全局 | 否 |
| 测试 | 全局 | 否 |
| 设置 | 全局 | 否 |
| 数据 / 分析 / 变换 | 工程内 | 是 |
