# 统计分析

在**工程工作区 → 分析** 中运行，结果为文本报告 + 可选图表，可分享。

## 过程分类

### 描述与探索
- 描述统计：N、均值、SD、方差、偏度峰度、分位数、95% CI
- 频率分析、直方图、条形图、散点图
- 箱线图（须 / 四分位箱 / 中位数 / 均值 / 离群点，可按分组并列，最多并列 6 组）
- 误差条图（均值与 95% 置信区间，单组时为横向单行）
- 正态 Q-Q 图（散点 + y = x 参考线 + 轴标题）
- 正态性检验（KS + 偏度峰度）

### 比较均值
- 单样本 / 独立 / 配对 t 检验（Levene 自动 Welch）
- 单因素 ANOVA（η²、ω²、Levene）
- 协方差分析 ANCOVA（控制协变量后的组间比较，Type III 平方和）
- 分层均值 MEANS
- 事后比较 Tukey HSD

### 相关与关联
- Pearson / Spearman 相关矩阵（成对删除，见[缺失值口径](/guide/missing-values)）
- 交叉表卡方：χ²、似然比、φ、Cramér's V

### 回归与聚类
- 简单 / 多元线性回归（VIF、DW、标准化 β）
- 逐步回归
- 逻辑回归（OR、伪 R²、正确率）
- 多项 logistic 回归（三分类及以上名义因变量）
- K-Means 聚类（含簇中心散点图）
- 主成分因子分析（PCA 载荷 + 碎石图，碎石图只绘制已提取的主成分）
- ROC / AUC

### 非参数与信度
- Mann-Whitney U（含结校正）、Wilcoxon、Kruskal-Wallis H
- 有序趋势检验（Jonckheere-Terpstra）：分组本身有序时的单调趋势
- 置换检验：两独立样本均值差 / 配对差，小样本下不依赖分布假设（可给出精确枚举）
- Cronbach α（项总相关、删除项后 α）

## 报告内容

- 组统计量 / 描述表
- 检验表（t / F / χ²、df、p）
- 效应量（Cohen d、η²、Cramér's V…）
- 备注（Levene 结果、方差齐性判断）
- 可选图表：箱线图、误差条图、Q-Q 图、碎石图、直方图、条形图、散点图、聚类散点图（图表与表格数据口径一致）

p 值按 APA 格式（`<.001` / `.032`）并用 `* ** ***` 标注。

### 导出

- 右上角可**分享整份报告**（纯文本）或**导出 HTML / Markdown 文件**。
- 每个分区标题右侧的菜单可**单独复制 / 导出本节**（Markdown 或 HTML），文件名形如 `stats-报告名-分区标题-20261015.md`；中文标题回退为分区序号。

## 使用步骤

1. 打开工程 → 分析
2. 选择过程
3. 勾选变量 / 分组
4. **运行分析**
5. 右上角分享纯文本报告，或按分区单独导出
