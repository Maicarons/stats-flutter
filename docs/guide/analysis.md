# 统计分析

分析页按类别组织统计过程，选择过程后配置参数并一键运行，结果以文本报告 + 图表呈现。

## 分析流程

1. 在底部导航进入 **分析**
2. 选择过程（如「独立样本 t 检验」）
3. 勾选分析变量、分组变量等
4. 点击 **运行分析**
5. 查看报告；右上角可 **分享** 纯文本结果

## 过程分类

### 描述与探索
- 描述统计：N、均值、标准差、方差、偏度峰度、分位数、95% CI
- 频率分析：频数、百分比、累计百分比
- 直方图 / 条形图 / 散点图

### 比较均值
- 单样本 / 独立样本 / 配对样本 t 检验
- 独立样本自动做 Levene 方差齐性检验，必要时 Welch 校正
- 单因素 ANOVA：F 检验、η²、ω²、Levene

### 相关与关联
- Pearson / Spearman 相关矩阵（含显著性）
- 交叉表卡方：χ²、似然比、φ、Cramér's V

### 回归与聚类
- 简单 / 多元线性回归：系数表、VIF、DW、ANOVA 表
- K-Means 聚类：中心点、簇大小、散点图

### 非参数与信度
- Mann-Whitney U、Wilcoxon 符号秩、Kruskal-Wallis H
- Cronbach α（含项总相关、删除项后 α）

## 报告解读

每个报告包含：

- **组统计量** / **描述统计** 表
- **检验表**（t / F / χ²、df、p）
- **效应量**（Cohen d、η²、Cramér's V 等）
- **备注**（如 Levene 结果、方差齐性判断）

p 值按 APA 风格格式化（`<.001` / `.032`），并用 `* ** ***` 标注显著性。
