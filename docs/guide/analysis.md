# 统计分析

在**工程工作区 → 分析** 中运行，结果为文本报告 + 可选图表，可分享。

## 过程分类

### 描述与探索
- 描述统计：N、均值、SD、方差、偏度峰度、分位数、95% CI
- 频率分析、直方图、条形图、散点图
- 正态性检验（KS + 偏度峰度）

### 比较均值
- 单样本 / 独立 / 配对 t 检验（Levene 自动 Welch）
- 单因素 ANOVA（η²、ω²、Levene）
- 分层均值 MEANS
- 事后比较 Tukey HSD

### 相关与关联
- Pearson / Spearman 相关矩阵
- 交叉表卡方：χ²、似然比、φ、Cramér's V

### 回归与聚类
- 简单 / 多元线性回归（VIF、DW、标准化 β）
- 逻辑回归（OR、伪 R²、正确率）
- K-Means 聚类
- 主成分因子分析（PCA 载荷）
- ROC / AUC

### 非参数与信度
- Mann-Whitney U、Wilcoxon、Kruskal-Wallis H
- Cronbach α（项总相关、删除项后 α）

## 报告内容

- 组统计量 / 描述表
- 检验表（t / F / χ²、df、p）
- 效应量（Cohen d、η²、Cramér's V…）
- 备注（Levene 结果、方差齐性判断）

p 值按 APA 格式（`<.001` / `.032`）并用 `* ** ***` 标注。

## 使用步骤

1. 打开工程 → 分析
2. 选择过程
3. 勾选变量 / 分组
4. **运行分析**
5. 右上角分享纯文本报告
