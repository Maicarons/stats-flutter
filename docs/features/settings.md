# 设置与主题

底部导航最右侧进入 **设置**。

## 主题模式

| 模式 | 行为 |
|------|------|
| 跟随系统 | 跟随系统浅色/深色 |
| 浅色 | 强制浅色 |
| 深色 | 强制深色 |

## 主题色

内置 8 种 Material 3 种子色：

蓝 · 紫 · 青绿 · 珊瑚 · 红 · 亮蓝 · 品红 · 石墨

点击色球即时切换，整套 ColorScheme 自动派生（Primary / Container / Surface 等）。

## 语言

| 选项 | 行为 |
|------|------|
| 跟随系统 | 使用系统 locale |
| English | 强制英文 |
| 中文 | 强制中文 |

切换即时生效，无需重启。实现基于 Flutter 官方 `flutter gen-l10n`。

## 关于与重置

- **关于**：应用简介与版本号
- **重置**：恢复默认主题、主题色、语言，并重载示例数据（有确认对话框）

设置通过 `shared_preferences` 持久化，重置会清除对应键。
