# Internationalization

StatLab uses Flutter's official **gen-l10n**.

```
lib/l10n/app_en.arb
lib/l10n/app_zh.arb
lib/l10n/app_localizations.dart   # generated
```

```dart
import 'package:stats_flutter/l10n/app_localizations.dart';

final l10n = AppLocalizations.of(context);
Text(l10n.tabData);
```

Supported locales: `en`, `zh`. Add a new locale by creating `app_<code>.arb` and registering it in `MaterialApp.supportedLocales`.
